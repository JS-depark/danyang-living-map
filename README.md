# 단양, 사람이 모여 사는 곳

단양의 산과 물 사이에 형성된 거주 분포를 3D 지형 위에 표현한 웹 지도입니다.
옛 KBS 중계소 부지의 위치를 함께 살펴볼 수 있습니다.

## 지도 사용

- 드래그로 이동하고, 휠로 확대합니다. 오른쪽 드래그로 지형을 회전합니다.
- 단양군 전체, 단양읍, 중계소 부지 보기로 전환할 수 있습니다.
- 구 크기, 인구 색상, 지형 높이 배율을 조절할 수 있습니다.
- 부지 라벨을 드래그해 옮기고, 현재 화면을 PNG로 저장할 수 있습니다.

## 자료와 표현

2023년 인구 26,473명을 2024년 6월 30일 기준 집계구 59개와 결합했습니다.
집계구별 총인구를 주거용 건물 19,270개의 건물면적 × 지상층수 비율로 배분한 뒤,
100m 구역별로 합산해 4,292개의 같은 크기 구로 표시했습니다.

구의 색은 인구 추정치를 뜻합니다. 건물별 실제 거주인구를 뜻하지 않으며,
공실, 관광객, 건물 내 비주거 공간은 반영하지 않습니다.
집계구별 인구 합계는 유지했습니다. 구역별 추정값은 지도에서 CSV로 내려받을 수 있습니다.

제공한 DEM으로 화면용 지형을 만들었습니다. 지도 표시를 위해 경계 바깥을 가리고,
경계 부근의 빈 높이를 보완해 연회색 측면을 붙였습니다.
이 저장소에는 웹 지도에 필요한 가공 자료만 포함하며 원본 GIS 파일과 공모 문서는 포함하지 않습니다.

## 실행과 배포

별도 빌드나 API 키 없이 정적 웹 서버에서 실행됩니다.
로컬 확인 시 이 폴더에서 `python -m http.server 8765`를 실행한 뒤
`http://localhost:8765/`를 엽니다. HTML 파일을 직접 여는 대신 웹 서버를 사용해야 합니다.

GitHub Pages는 Settings → Pages에서 `Deploy from a branch`, `main`, `/ (root)`로 설정합니다.
상대 경로를 사용하므로 저장소 이름 아래의 Pages 주소에서도 실행됩니다.
변경 내용을 `main`에 올리면 Pages에 반영됩니다.
