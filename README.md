# 단양, 사람이 모여 사는 곳

단양의 지형과 거주 분포를 함께 살펴보는 웹 지도입니다.
산과 물 사이에 형성된 생활 공간과 옛 KBS 중계소 부지의 위치를 입체로 표현했습니다.

## 지도 사용

- 드래그로 이동하고 휠로 확대·축소합니다. 오른쪽 드래그로 지형을 회전합니다.
- ‘단양군 전체’, ‘단양읍 · 부지’, ‘부지 가까이’로 이동할 수 있습니다.
- ‘위에서 보기’를 누르면 북쪽을 위로 두고 지도를 수직으로 내려다봅니다.
- ‘지도 표현’에서 100m 추정 인구, 건물, 집계구 총인구, 부지 경계를 각각 켜거나 끌 수 있습니다.
- 건물과 집계구를 클릭하면 해당 자료의 상세 정보를 볼 수 있습니다.
- 구 크기, 인구 색상, 지형 높이 배율을 조절할 수 있습니다.
- 부지 라벨을 드래그해 옮기고, 선택한 레이어와 범례를 포함한 화면을 PNG로 저장할 수 있습니다.

## 자료와 표현

2023년 총인구 26,473명과 2024년 6월 30일 기준 집계구 59개를 사용했습니다.
집계구별 인구를 주거용 건물의 면적과 층수에 따라 배분한 뒤,
100m 구역별로 합산해 같은 크기의 구 4,292개로 표시했습니다. 집계구별 인구 합계는 유지했습니다.

100m 구역의 인구는 추정값이며, 건물별 실제 거주인구를 뜻하지 않습니다.
공실과 관광객, 건물 안의 비주거 공간은 반영하지 않았으며,
용도가 미상이거나 비주거용인 건물은 인구 배분에서 제외했습니다.

건물 레이어는 원본 SHP의 도형과 건물명·용도·층수·도형 면적·사용승인일을 표시합니다.
단양 경계 안의 건물 54,122개를 표시하며, 원본 건물 54,141개 중 경계 밖 또는 빈 도형 19개는 표시하지 않습니다.
건물의 소속 집계구와 집계구별 건물 수는 건물 도형 내부의 대표점을 기준으로 연결했습니다.
집계구 레이어의 총인구는 통계 자료의 값입니다. 건물별 실제 거주인구 자료는 포함하지 않습니다.

이 저장소에는 웹 지도에 필요한 가공 자료가 포함되어 있습니다.
건물의 내부 작업 경로와 원본 GIS 파일, 공모 문서는 포함하지 않습니다.

## 실행과 배포

별도 빌드나 API 키 없이 정적 웹 서버에서 실행됩니다.
로컬 확인 시 이 폴더에서 `python -m http.server 8765 --bind 127.0.0.1`을 실행한 뒤
`http://localhost:8765/`를 엽니다.

GitHub Pages는 Settings → Pages에서 `Deploy from a branch`, `main`, `/ (root)`로 설정합니다.
상대 경로를 사용하므로 저장소 이름 아래의 Pages 주소에서도 실행됩니다.
변경 내용을 `main`에 올리면 Pages에 반영됩니다.
